# Everyday Wonder — The Hand Arrives First

A single-sentence entry for the make.fun bounty
[Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3):
one sentence, at most 200 characters, that makes a small everyday moment
strange and new.

The sentence, written by `main.py` to `/output/entry.txt`:

> The escalator handrail moved faster than the steps, so my hand reached
> the top a moment before the rest of me did.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13, standard library only. No dependencies, no network, no secrets.
